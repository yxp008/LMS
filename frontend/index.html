SMTP 邮件配置

SMTP服务器地址，如 smtp.qq.com、smtp.163.com、smtp.gmail.com
SSL加密端口通常为465，STARTTLS端口为587
用于发送告警邮件的邮箱地址
不是邮箱登录密码！需在邮箱设置→SMTP服务中开启并获取授权码
常用 SMTP 配置参考:
QQ邮箱: smtp.qq.com / 端口465 / 开启方法: 设置→账户→POP3/IMAP/SMTP→开启SMTP→生成授权码
163邮箱: smtp.163.com / 端口465 / 开启方法: 设置→POP3/SMTP/IMAP→开启SMTP→设置授权码
Gmail: smtp.gmail.com / 端口465 / 需开启"两步验证"后生成应用专用密码
Outlook: smtp.office365.com / 端口587 / 使用登录密码或应用密码
